GARAGEY - PRUEBA LOCAL EN MÓVIL

Esta versión está preparada para probar Garagey como aplicación local/PWA.

IMPORTANTE:
Un navegador Android no permite instalar directamente un archivo ZIP como aplicación.
Para probarla correctamente:

OPCIÓN RECOMENDADA:
1. Descomprime esta carpeta.
2. Copia los archivos a un pequeño servidor web local o hosting temporal.
3. Abre index.html mediante HTTPS.
4. En Chrome Android pulsa "Instalar aplicación" o "Añadir a pantalla de inicio".

Para una prueba totalmente local sin servidor, también puedes abrir index.html
directamente con Chrome, aunque algunas funciones PWA (como Service Worker)
pueden requerir HTTPS o localhost.

Los datos se guardan localmente en el dispositivo/navegador.

Cuando Garagey pase a APK Android:
- Se mantendrá el mismo modelo de datos.
- Podrán migrarse los datos.
- Las futuras actualizaciones conservarán la información.
